# GUIA DA CLASSIFICAÇÃO TURÍSTICA SDE-SP
## Metodologia de Classificação e Caracterização Turística dos Municípios Paulistas

---

## 1. VISÃO GERAL DA METODOLOGIA

A **Classificação Turística SDE-SP** é um sistema transparente e determinístico que organiza os 645 municípios paulistas em 6 categorias baseadas em:

1. **Reconhecimento Institucional** (Mapa do Turismo, MIT, Estância Turística)
2. **Avaliação Qualitativa** (Oportunidades turísticas identificadas pelos Diretores Regionais)
3. **Inteligência Territorial** (Atrativos principais, rotas, capacidades)

**Princípio fundamental**: A oportunidade turística identificada localmente é elemento obrigatório para classificação como "Destino Turístico" (Consolidado, Estruturado ou Em Desenvolvimento).

## 3. DESCRIÇÃO DETALHADA DE CADA CATEGORIA

### CATEGORIA 1: DESTINO TURÍSTICO CONSOLIDADO
**87 municípios | 13,5%**

#### Critérios de Classificação
```
├─ Categoria = "Município Turístico" (MTur)           [✓ Reconhecimento Nacional]
├─ Tem_Oportunidade_Turistica = "Sim"                 [✓ Avaliação SDE]
└─ (MIT = "Sim" OU Estancia_Turistica = "Sim")        [✓ Reconhecimento Estadual]
```

#### O que significa
Município consolidado como destino turístico:
- ✓ Integra o Mapa do Turismo Brasileiro (categoria Município Turístico)
- ✓ Reconhecido como Município de Interesse Turístico (MIT) ou Estância Turística
- ✓ Possui vocação/oportunidade turística identificada pelo SDE

#### Exemplos de Perfil
- Municípios com infraestrutura consolidada
- Rotas estabelecidas e fluxos de turistas regulares
- Oferta diversificada de atrativos e serviços
- Gestão turística formalizada

#### Implicações para Política
- **Prioridade**: Consolidação, expansão, posicionamento de marca
- **Ações**: Qualificação de infraestrutura, marketing, inovação
- **Escopo**: Regional ou estadual
- **Investimento**: Sustentabilidade e competitividade

---

### CATEGORIA 2: DESTINO TURÍSTICO ESTRUTURADO
**41 municípios | 6,4%**

#### Critérios de Classificação
```
├─ Categoria = "Município Turístico" (MTur)           [✓ Reconhecimento Nacional]
├─ Tem_Oportunidade_Turistica = "Sim"                 [✓ Avaliação SDE]
├─ MIT = "Não"                                        [✗ Sem reconhecimento estadual]
└─ Estancia_Turistica = "Não"                         [✗ formal]
```

#### O que significa
Município turístico reconhecido nacionalmente mas sem formalização estadual:
- ✓ Integra o Mapa do Turismo como Município Turístico
- ✓ Oportunidade turística identificada
- ✗ Sem reconhecimento como MIT ou Estância (ainda)

#### Exemplos de Perfil
- Destinos emergentes já reconhecidos pelo MTur
- Estrutura base estabelecida mas em fase de fortalecimento
- Possíveis candidatos a MIT ou Estância

#### Implicações para Política
- **Prioridade**: Estruturação, reconhecimento estadual
- **Ações**: Formalização (MIT/Estância), qualificação, networking
- **Escopo**: Regional, com potencial estadual
- **Investimento**: Apoio à consolidação estrutural

---

### CATEGORIA 3: DESTINO TURÍSTICO EM DESENVOLVIMENTO
**101 municípios | 15,7%**

#### Critérios de Classificação
```
├─ Categoria = "Complementar" OU "Apoio ao Turismo"   [✓ Integra Mapa]
└─ Tem_Oportunidade_Turistica = "Sim"                 [✓ Avaliação SDE]
```

#### O que significa
Município já no Mapa do Turismo em categoria complementar/apoio, mas com potencial de evolução:
- ✓ Integra o Mapa do Turismo
- ✓ Oportunidade turística identificada para upgrade
- ✗ Ainda não em categoria "Município Turístico"

#### Exemplos de Perfil
- Destinos com atrativos complementares
- Municípios de apoio (hospedagem, alimentação, etc.)
- Potenciais para evolução de categoria

#### Implicações para Política
- **Prioridade**: Desenvolvimento, preparação para upgrade
- **Ações**: Fortalecimento de atrativos, investimento em infraestrutura
- **Escopo**: Regional ou local
- **Investimento**: Aceleração de desenvolvimento

---

### CATEGORIA 4: POTENCIAL TURÍSTICO EMERGENTE
**129 municípios | 20,0%**

#### Critérios de Classificação
```
├─ Categoria = "Não integra o Mapa do Turismo"       [✓ Fora do Mapa]
└─ Tem_Oportunidade_Turistica = "Sim"                [✓ Avaliação SDE]
```

#### O que significa
Município ainda não reconhecido nacionalmente, mas com clara vocação turística:
- ✗ Não integra o Mapa do Turismo Brasileiro (ainda)
- ✓ Oportunidade turística identificada pelos Diretores
- → Candidato prioritário para integração ao Mapa

#### Exemplos de Perfil
- Municípios com atrativos não consolidados
- Potencial turístico ainda em exploração
- Possíveis candidatos para próxima edição do Mapa

#### Implicações para Política
- **Prioridade**: Reconhecimento, integração ao Mapa
- **Ações**: Diagnóstico de potencial, preparação de dossiê Mapa
- **Escopo**: Local, com potencial regional
- **Investimento**: Estruturação básica de infraestrutura

---

### CATEGORIA 5: RECONHECIDO SEM OPORTUNIDADE TURÍSTICA IDENTIFICADA
**39 municípios | 6,0%**

#### Critérios de Classificação
```
├─ Tem_Oportunidade_Turistica = "Não"                [✗ Avaliação SDE]
└─ (MIT = "Sim" OU Estancia_Turistica = "Sim")       [✓ Reconhecimento Estadual]
```

#### O que significa
Município com reconhecimento estadual formal, mas sem oportunidade turística identificada na avaliação de 2026:
- ✓ Reconhecido como MIT ou Estância Turística
- ✗ Sem oportunidade turística identificada pelos Diretores
- → Pode integrar ou não o Mapa do Turismo

#### ⚠️ IMPORTANTE
**NÃO significa que o município não possui turismo!** Significa apenas que a avaliação de 2026 não identificou uma vocação/oportunidade turística específica para desenvolvimento.

#### Exemplos de Perfil
- Municípios com reconhecimento formal mas perfil não turístico
- Áreas com termalismo ou lazer mas sem estrutura de turismo
- Possíveis casos a revisar em próximas avaliações

#### Implicações para Política
- **Prioridade**: Monitoramento, análise de potencial
- **Ações**: Diagnóstico qualitativo, diálogo com Diretor Regional
- **Escopo**: Local
- **Investimento**: Pesquisa e avaliação

---

### CATEGORIA 6: SEM RECONHECIMENTO OU OPORTUNIDADE TURÍSTICA IDENTIFICADA
**248 municípios | 38,4%**

#### Critérios de Classificação
```
├─ Tem_Oportunidade_Turistica = "Não"                [✗ Avaliação SDE]
├─ MIT = "Não"                                       [✗ Sem reconhecimento]
├─ Estancia_Turistica = "Não"                        [✗ estadual]
└─ (Fora do Mapa OU no Mapa sem oportunidade)       [✗ ou potencial]
```

#### O que significa
Município para o qual nenhuma das bases de reconhecimento institucional foi identificada e também sem oportunidade turística avaliada:
- ✗ Não integra Mapa do Turismo OU integra mas sem potencial
- ✗ Sem MIT, sem Estância Turística
- ✗ Sem oportunidade turística identificada

#### ⚠️ IMPORTANTE
**NÃO afirma que o município não possui turismo!** Significa que, nas bases utilizadas nesta metodologia, não foram encontrados indicadores de reconhecimento ou potencial turístico.

#### Exemplos de Perfil
- Municípios com economia não turística
- Áreas rurais ou industriais
- Possíveis nichos turísticos não mapeados
- Candidatos a futuro diagnóstico

#### Implicações para Política
- **Prioridade**: Análise, pesquisa de potencial
- **Ações**: Diagnóstico de mercado, prospecção
- **Escopo**: Local
- **Investimento**: Pesquisa exploratória

## 5. COMO USAR A BASE PROCESSADA

### Arquivo: base_oportunidades_turisticas_sp_PROCESSADA.xlsx

#### Aba Principal: Base_Consolidada

Para cada município (645 linhas):

**Coluna de Classificação**: `Classificacao_Turistica_SDE`
- Valor direto da categoria (1-6)
- Use para filtrar, agrupar ou segmentar

**Colunas de Suporte**:
- `Integra_Mapa_Turismo`: Validar integração ao Mapa (Sim/Não)
- `Reconhecimento_MTUR`: Ver o nível de reconhecimento pelo MTur
- `Reconhecimento_Estadual`: Ver se é MIT/Estância/Ambos/Nenhum
- `Tem_Oportunidade_Turistica`: Validar base de oportunidade

**Colunas de Caracterização**:
- `Oportunidade Turística`: Tipo de vocação turística
- `Atrativo_Turistico`: Principal atrativo identificado
- `Rotas_Turisticas`: Rotas produtivas que integra
- `Numero_Meios_Hospedagem`, `Numero_Leitos`: Infraestrutura
- `Numero_Empregos_Hoteis`, `Numero_Empregos_Restaurantes`: Mercado de trabalho
- `Numero_Empresas_Hospedagem`, `Numero_Empresas_Restaurantes`: Estrutura econômica

#### Aba de Validação: Validacao_Classificacao_Turistica

Confirma:
- ✓ Universo completo (645 municípios)
- ✓ Distribuição por categoria
- ✓ Testes de integridade lógica
- Use para auditar processamento

## 6. EXEMPLOS DE USO

### Caso 1: Filtrar Destinos Consolidados
```
WHERE Classificacao_Turistica_SDE = "Destino Turístico Consolidado"
```
Resultado: 87 municípios de máxima prioridade para políticas de qualificação

### Caso 2: Identificar Candidatos ao Mapa
```
WHERE Classificacao_Turistica_SDE = "Potencial Turístico Emergente"
ORDER BY Numero_Oportunidade DESC
```
Resultado: 129 municípios para dossiê de integração ao Mapa

### Caso 3: Analisar Mercado de Trabalho por Categoria
```
SELECT Classificacao_Turistica_SDE,
       SUM(Numero_Empregos_Hoteis) as Empregos_Hoteis,
       SUM(Numero_Empresas_Hospedagem) as Empresas,
       COUNT(*) as Municipios
GROUP BY Classificacao_Turistica_SDE
ORDER BY Empregos_Hoteis DESC
```

### Caso 4: Monitorar MIT sem Oportunidade
```
WHERE Classificacao_Turistica_SDE = "Reconhecido sem Oportunidade Turística Identificada"
  AND MIT = "Sim"
```
Resultado: 39 municípios para reavaliação

## 8. PONTOS DE ATENÇÃO

### Município em Mais de uma Base?
É normal. A mesma cidade pode:
- Ser MIT E integrar o Mapa
- Ser Estância E não integrar o Mapa
- Ter estrutura hoteleira mas sem oportun. turística

A classificação resolve essas sobreposições com regra única.

### Dados Faltantes em Indicadores Econômicos?
Significa que a atividade não foi registrada em RAIS 2025:
- Possível empresa informal
- Atividade sazonal não registrada
- Período de revisão

Não invalida a classificação turística.

### Oportunidade Turística "Não há"?
Pode significar:
- Município sem vocação turística detectada
- Turismo não é prioridade desenvolvimentista
- Estrutura não consolidada para avaliar

Revisão em próximo ciclo é possível.
